# POO — Herança e Classes

Exercícios em **Java** da disciplina de Programação Orientada a Objetos (Tecnologia em Sistemas Inteligentes, Fatec Shunji Nishimura), com foco em classes, encapsulamento e vetores de objetos.

## Conteúdo

- `Tarefa`: classe com atributos privados, getters e setters
- `Main`: cria um vetor de tarefas e exibe seus dados

## Tecnologias

Java e Gradle.
